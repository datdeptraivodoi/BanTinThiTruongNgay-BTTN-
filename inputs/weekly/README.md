# Ảnh Reuters cho bản tin tuần

Mỗi thứ Sáu, trước 11:30, team tạo thư mục theo ngày thứ Sáu (ví dụ `2026-10-23/`) rồi tải lên 6 ảnh chụp biểu đồ Reuters/LSEG:

| Tên file | Biểu đồ |
|---|---|
| `eurusd.png` | Tỷ giá EUR-USD |
| `usdjpy.png` | Tỷ giá USD-JPY |
| `arabica.png` | Giá café Arabica |
| `robusta.png` | Giá café Robusta |
| `brent.png` | Giá dầu Brent |
| `gasoline.png` | Giá xăng |

Cách tải trên web GitHub: mở thư mục `inputs/weekly`, chọn **Add file → Upload files**, kéo 6 ảnh vào và ghi đường dẫn thư mục `2026-10-23/` ở ô tên file, rồi **Commit changes**.

Ảnh được co vào đúng khung của file mẫu, nên chụp theo tỷ lệ gần giống khung: rộng khoảng 9 cm, cao 5–5,5 cm (tỷ lệ khoảng 1,7 : 1). Thiếu ảnh nào thì bản tin hiện khung "Chưa có ảnh Reuters tuần này" và email review báo thiếu.
